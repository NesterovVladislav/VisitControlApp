# Дизайн-система приложения ДоброВход

Общие компоненты для React Native и Expo Web импортируются из `components/ui`. Примеры доступны по ссылке «UI Kit» на экране входа dev-сборки и по адресу `/ui-kit` в web-режиме. В публичной сборке маршрут закрыт. Каталог работает с текущей системной или выбранной в приложении темой.

- Семантическая палитра находится в `constants/palette.ts`. Компоненты получают её через `usePalette` и `makeStyles`. Для основных действий UI Kit используем пару `actionPrimary` / `onActionPrimary` с читаемым контрастом в обеих темах.
- `constants/ui-tokens.ts` задаёт шкалы отступов, радиусов, размеров текста и контролов. Раскладка и навигация принадлежат экрану.
- `FormCard` задаёт поверхность и ширину короткой формы. `FormField` показывает подпись, подсказку или ошибку, поддерживает фокус и блокировку. `PasswordField` добавляет доступное управление видимостью.
- `ActionButton` имеет основной и текстовый варианты, поддерживает фокус, загрузку и блокировку. `StatusMessage` показывает информационные, ошибочные и успешные состояния.
- `CodeField` отображает шесть ячеек с одним полем для клавиатуры и вставки. Запрашивает подсказку автозаполнения ОС. Отправка и обработка кода принадлежат экрану.
- Для новых форм использовать общие компоненты, проверять обе темы, узкий экран, клавиатуру и видимость ошибок. Добавлять в каталог полезные состояния по мере развития системы.
